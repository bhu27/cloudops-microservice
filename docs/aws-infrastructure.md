AWS Infrastructure

Overview

The CloudOps Enterprise Platform uses AWS services to demonstrate
cloud infrastructure, application deployment, serverless computing,
storage, database integration, monitoring, and security.

AWS Services

Amazon EC2
Used to host and run the application environment.

AWS Lambda
Used to run the serverless API.

API Gateway
Used to expose the Lambda function through an HTTP API.

Amazon RDS
Used for relational database infrastructure.

Amazon S3
Used for cloud object storage.

 Amazon CloudWatch
Used for monitoring application and AWS resource metrics.

AWS CloudTrail
Used for activity logging and auditing.

 Security Groups
Used to control network access to AWS resources.
